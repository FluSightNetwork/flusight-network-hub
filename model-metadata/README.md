# model-metadata

One YAML file per model ID, generated by `src/07_metadata.R` from each model's `metadata.txt` in the
source repository. `forecast_mode` is `real-time`, `training` or `cross-validated`; `paired_model_id`
links a model's real-time and training/cv IDs. Do not combine IDs from different records in one
analysis (see the top-level README).
