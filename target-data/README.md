# target-data

Generated by `src/08_target_data.R`; configured by `hub-config/target-data.json`.

- `time-series.csv`: weekly wILI (`observation`, one decimal, as scored by FluSight) for `target` = `ili perc`,
  by `target_end_date` and `location`, for every week some forecast targets. `truth_source` gives the origin of
  each row: FSN's `scores/target-multivals.csv`, or derived from an ILINet snapshot (2019/20 and the week ending
  2019-06-22) with FSN's own definitions (`src/compute_truths.R`).
- `oracle-output.parquet`: hubverse oracle output keyed like the model output (`origin_date`, `location`,
  `target`, `horizon`, `target_end_date`, `output_type`, `output_type_id`). For pmf, `oracle_value` is 1 for
  the observed bin and 0 for the others; for `median`, it is the observed wILI. Seasonal targets repeat their
  season's truth for every `origin_date`.

Rules: tied peak weeks in FSN's truths → week with the highest unrounded ILINet wILI (`src/peak_week_ties.csv`);
2019/20 onset/peak use a season ending EW09-2020 (week ending 2020-02-29) to avoid COVID-19-affected weeks.

Validation (`validation/target-data-validation.csv`): hubValidations passes except `target_tbl_output_type_ids`,
which is not round-aware (it expects every season's week-date bins for every task). A round-aware replacement
check confirms all 25,641 oracle pmf tasks have exactly their season's bins and one observed bin.
