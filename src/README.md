# Conversion pipeline

Run from the repository root, in order. Requires a bare mirror of the source repository at
`.cache/cdc-flusight-ensemble.git` (`git clone --mirror https://github.com/FluSightNetwork/cdc-flusight-ensemble.git`)
and of CDC's submissions at `.cache/FluSight-forecasts.git` (`git clone --mirror https://github.com/cdcepi/FluSight-forecasts.git`),
R with data.table, arrow, hubAdmin, hubValidations, hubData, yaml, jsonlite.

| Script | Step |
|---|---|
| `00_config.R` | paths, git and MMWR helpers (sourced by every step) |
| `01_manifest.R` | every version of every forecast file in the source history → `validation/source-history.csv`, training pin |
| `02_file_map.R` | which source version becomes each hub file (real-time preferred, then training, then late; model versions; cutoffs, exclusions) → `validation/file-map*.csv` |
| `03_standardise.R` | extract and standardise each selected version; structure/quality profile |
| `05_repair_cv.R` | repaired copies of the ensemble builds (week-52/53 stacking bug) |
| `04_convert.R` | renormalise/exclude, compute medians, write `model-output/` (run after 05) |
| `07_metadata.R` | `model-metadata/`, `auxiliary-data/`, change and exclusion logs |
| `fetch_ilinet.R`, `resolve_peak_week_ties.R`, `compute_truths.R` | ILINet snapshots, tie resolution, FSN truth definitions |
| `08_target_data.R` | `target-data/` |
| `09_config.R` | `hub-config/` |
| `10_validate_roundtrip.R` | proves every hub value equals the source value (or its logged change) |
| `10_validate_hubverse.R` | hubValidations on every file; hubData load check |
| `11_smoke_modelimportance.R` | modelimportance on hub data |
| `diag_cv_ensembles.R` | diagnostic that reproduced FSN's cv ensembles and found the stacking bug |

Inputs maintained by hand: `model_ids.csv` (source directory → model IDs), `model_versions.csv`
(retrained models → one ID per version), `ensemble_builds.csv` (FSN's pre-season ensemble builds → one ID per method per build), `baselines.csv`
(CDC regional baselines), `peak_week_ties.csv` (generated by `resolve_peak_week_ties.R`).
