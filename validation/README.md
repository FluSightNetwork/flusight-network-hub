# validation

Evidence for the conversion (all generated by `src/`):

- `source-history.csv`, `source-refs.csv`, `source-pin.csv`: every version of every source forecast file.
- `file-map*.csv`: the selected source version for every hub file; excluded, non-selected and superseded versions; review items.
- `ensemble-components.csv`: FSN ensemble components per operational season, mapped to hub model IDs.
- `profile-files.csv`: structure/quality profile of each selected file.
- `changes.parquet`, `conversion-stats.csv`: every renormalised/excluded forecast; per-file row accounting.
- `cv-repair*.csv/.parquet`, `diag-cv-ensembles.csv`: cv-ensemble stacking bug and repair.
- `roundtrip.csv`, `duplicate-check.csv`: every hub value equals its source value (or logged change); duplicates byte-identical.
- `truth-recompute-*.csv`: the truth method reproduces FSN's truths exactly.
- `hubverse-validation*.csv`, `smoke-modelimportance.csv`: hubValidations and downstream checks.
