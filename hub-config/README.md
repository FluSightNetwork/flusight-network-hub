# hub-config

Hubverse configuration (schema v6.0.0), generated by `src/09_config.R`.

- `tasks.json`: one round per season (2010/11–2019/20), `round_id` = `origin_date`. Each round has model
  tasks for `ili perc` (pmf + median), `season peak perc` (pmf), and the season's own week-date bins
  for `season onset wk` / `season peak wk` (pmf). `target_end_date` is a derived task ID.
- `admin.json`: **placeholder** hub identity (name, maintainer, contact, repository) — not decided yet.
- `model-metadata-schema.json`: fields for this archive, including `forecast_mode` and `paired_model_id`.
